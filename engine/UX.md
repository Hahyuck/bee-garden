# Bee Garden 시스템 메뉴 설계

첫 방문자는 하고 싶은 활동을 고르거나 게임 아이디어를 입력한다. 플레이 중에는 위쪽의 모드 선택과 시스템 메뉴를 통해 같은 기능으로 돌아온다. 모드가 지정된 공유 링크는 해당 장면으로 바로 들어간다.

| 화면 | 사용자가 해결할 일 | 화면에서 제공하는 동작 |
| --- | --- | --- |
| 플레이 | 무엇을 할 수 있는지 알아보기 | 모드마다 한 줄로 플레이 목표를 설명한다. 카드의 숫자·문자는 실제 전환 단축키와 같다. 현재 모드는 왼쪽 띠로 표시한다. |
| AI 게임 제작 | 아이디어를 새 게임으로 만들거나 현재 게임 개편하기 | 첫 화면 중앙에 적은 문장을 이어받는다. 작업과 생성 방법을 고르면 모드, 화면 표현, 날씨, 시간, 목표를 미리 보여준다. 적용 버튼을 누르면 플레이가 시작된다. |
| 도구와 설정 | 모델, 화면 표현, 환경 바꾸기 | 화면 스타일·GLB, 캐릭터·모델 샘플, 조명, 엔진 활용법, 소리로 진입한다. 날씨와 시간은 이 화면에서 직접 조절한다. |
| 플레이 HUD | 현재 위치와 다음 행동 판단하기 | 미니맵은 북쪽을 위로 유지한다. 삼각형은 플레이어 방향, 금색 점은 항해 부표나 낚시찌다. 아래에는 현재 모드 조작을, 개별 계기에는 속도·장력 같은 실시간 상태를 표시한다. |

## 대표 동선

- **낚시** — 플레이에서 8 낚시를 고른다. 낚싯대와 떡밥을 정한 후 방향을 돌리고 던진다. 입질 때 챔질하면 장력계가 나타난다. 줄을 감고 풀며 물고기를 끌어올린 뒤 어망에서 어종과 무게를 확인한다.
- **게임 제작** — 첫 화면에 “비 오는 해안에서 물고기 세 마리를 잡는 픽셀 게임”을 입력한다. AI로 만들기를 눌러 초안을 생성하고 목표를 확인한다. 플레이를 마친 뒤 화면 스타일·GLB 도구에서 프로젝트 JSON으로 내보낼 수 있다.
- **FPS** — 게임 화면을 클릭하면 마우스가 조준점에 고정된다. Esc를 누르면 플레이와 환경 시간이 멈추고 커서가 나타난다. 계속하기로 같은 위치에서 재개한다.
- **캐릭터 탐험** — W와 Shift로 달리는 중 Space로 점프한다. 높은 벽을 향해 전진하며 점프하면 벽을 잡는다. 앞뒤 입력으로 오르내리고 Space로 놓는다.

## 입력과 피드백

시스템 메뉴는 키보드 포커스를 안쪽에 유지하는 대화상자다. Tab으로 항목을 이동하고 Enter로 실행하며 Esc로 닫는다. 터치 화면에서는 모드 목록과 낚시 동작을 버튼으로 조작한다. AI 응답 대기, 연결 실패, 낚시 입질, 줄 끊어짐, 어망 저장은 해당 행동 옆에 표시한다. 브라우저의 모션 줄이기 설정을 사용하면 낚시 화면 흔들림이 줄어든다.

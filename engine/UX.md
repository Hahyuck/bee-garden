# Bee Garden 월드 메뉴

첫 방문자는 하고 싶은 활동을 고르거나 게임 아이디어를 입력한다. 상단의 현재 모드를 누르면 그 아래 한 줄에 모든 모드가 펼쳐진다. 하단의 제작 입력칸은 플레이 중에도 사용할 수 있다. 모드가 지정된 공유 링크는 해당 장면으로 바로 들어간다.

| 화면 | 사용자가 해결할 일 | 화면에서 제공하는 동작 |
| --- | --- | --- |
| 플레이 | 무엇을 할 수 있는지 알아보기 | 숫자·문자는 전환 단축키다. 현재 모드는 밝은 녹색으로 표시한다. 좁은 화면에서는 좌우로 밀어 선택한다. |
| AI 게임 제작 | 아이디어를 새 게임으로 만들거나 현재 게임 개편하기 | 하단의 제작할 게임에 아이디어를 입력한다. Codex 또는 Claude Code를 골라 AI로 열기를 누르면 선택한 작업창에 요청문과 현재 게임 설정이 채워진다. |
| 게임 비주얼 | 플레이 화면 표현 고르기 | 상단 버튼에서 화면 스타일, 픽셀 해상도와 Fit을 조절한다. |
| 도구 | 모델과 환경 바꾸기 | GLB·프로젝트, 캐릭터·모델 샘플, 조명, 엔진 활용법, 소리로 진입한다. 날씨와 시간은 이 화면에서 직접 조절한다. |
| 플레이 HUD | 현재 위치와 다음 행동 판단하기 | 미니맵은 북쪽을 위로 유지한다. 삼각형은 플레이어 방향, 금색 점은 항해 부표나 낚시찌다. 아래에는 현재 모드 조작을, 개별 계기에는 속도·장력 같은 실시간 상태를 표시한다. |

## 대표 동선

- **낚시** — 플레이에서 8 낚시를 고른다. 낚싯대와 떡밥을 정한 후 방향을 돌리고 던진다. 입질 때 챔질하면 장력계가 나타난다. 줄을 감고 풀며 물고기를 끌어올린 뒤 어망에서 어종과 무게를 확인한다.
- **게임 제작** — 하단 제작할 게임에 “비 오는 해안에서 물고기 세 마리를 잡는 픽셀 게임”을 입력한다. Claude Code를 선택해 AI로 열기를 누르고, 새 브라우저 탭에서 저장소와 요청문을 확인한 뒤 보낸다. 플레이를 마친 뒤 GLB·프로젝트 도구에서 프로젝트 JSON으로 내보낼 수 있다.
- **FPS** — 모드를 선택하면 바로 마우스로 시선을 돌린다. 화면 가장자리에서 계속 선회한다. Esc를 누르면 플레이와 환경 시간이 멈추고 커서가 나타난다. 계속하기로 같은 위치에서 재개한다.
- **캐릭터 탐험** — W와 Shift로 달리는 중 Space로 점프한다. 높은 벽을 향해 전진하며 점프하면 벽을 잡는다. 앞뒤 입력으로 오르내리고 Space로 놓는다.

## 입력과 피드백

상단 버튼을 다시 누르거나 바깥을 누르면 하위 목록이 접힌다. Tab으로 이동하며 모드 목록에서는 좌우 화살표로 선택하고 Enter로 실행하거나 Esc로 닫는다. 터치 화면에서는 모드 목록과 낚시 동작을 버튼으로 조작한다. AI 작업창 열기와 요청문 복사 상태, 낚시 입질, 줄 끊어짐, 어망 저장은 해당 행동 옆에 표시한다. 브라우저의 모션 줄이기 설정을 사용하면 낚시 화면 흔들림이 줄어든다.

## Sacchan-VRC — SaccFlightAndVehicles

Copyright (c) 2021 Sacchan-VRC. Original VRChat package and prefabs: https://github.com/Sacchan-VRC/SaccFlightAndVehicles/tree/3216e53fecb1d9cd3c9c740688e0b8743bb283cb.

These static scenery exports use the original FBX geometry in the rest pose. Interactive Udon scripts, sounds, HUD, font and animation logic are separate from these GLBs. Textures, when present, are embedded. The floor and displayed height have been normalized to metres.

- `sacc-walkie.glb` — https://github.com/Sacchan-VRC/SaccFlightAndVehicles/blob/3216e53fecb1d9cd3c9c740688e0b8743bb283cb/AssetFiles/Shared/SaccWalkieTalkie.fbx
- `shoreline.glb` — https://github.com/Sacchan-VRC/SaccFlightAndVehicles/blob/3216e53fecb1d9cd3c9c740688e0b8743bb283cb/AssetFiles/Shoreline/Shoreline.fbx
- `stunt-plane.glb` — https://github.com/Sacchan-VRC/SaccFlightAndVehicles/blob/3216e53fecb1d9cd3c9c740688e0b8743bb283cb/AssetFiles/StuntPlane/stuntplane.fbx

The walkie-talkie includes display, keypad and casing finishes adapted for Web PBR. The Shoreline sports car uses a green paint finish derived from the original green variant, alloy wheels and smoked glazing. The stunt aircraft retains the original livery, normal and metallic maps. The static exhibition model uses the intact propeller mesh.

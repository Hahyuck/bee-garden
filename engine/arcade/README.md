# COASTLINE GT

1990년대 아케이드 스톡카 레이싱의 감각을 담은 오리지널 브라우저 게임입니다. 기존 garden engine 저장소의 Three.js를 사용합니다. 차량, 서킷, 로고, 지형, 관중, 효과음은 모두 새로 만든 절차적 자산입니다.

## 플레이

[COASTLINE GT 열기](https://hahyuck.github.io/bee-garden/engine/arcade/?style=pixel&raster=240&pixelFit=auto&day=11.5&weather=clear)

- 약 2.01km 해안 스피드웨이, 8대의 차량, 3랩.
- 3초 카운트다운 후 출발. 매 랩의 체크포인트 두 곳과 결승선을 순서대로 통과합니다.
- 표준: 시작 45초, 체크포인트마다 9초 추가. 입문: 시작 60초, 12초 추가. 마지막 결승선은 시간을 추가하지 않고 경기를 끝냅니다.
- 최고 기본 속도 300km/h, 자동 4단 변속. 직선에서 라이벌 뒤에 붙으면 슬립스트림이 쌓입니다. 옆 차선으로 빠진 직후에도 가속 효과가 잠깐 남습니다. 라이벌도 빈 차선을 찾아 추월합니다.
- 드리프트, 차량 접촉, 노면 밖 감속, 벽 충돌. 고속 진입 시 바깥으로 밀리는 힘이 커집니다. 진입 전에 짧게 제동하거나, 조향과 함께 Space를 눌러 속도를 내주고 안쪽 라인을 잡으세요. 뱅크가 높아지면 바깥으로 밀리는 힘이 줄어듭니다.
- 완주와 시간 초과는 별도 결과 화면으로 표시합니다. 완주 기록은 난이도별로 브라우저에 저장합니다.

| 입력 | 동작 |
|---|---|
| Enter | 시작 / 결과에서 재도전 |
| W / ↑ | 가속 |
| S / ↓ | 브레이크 |
| A D / ← → | 좌우 조향 |
| Space + 조향 | 드리프트 |
| C | 추격 / 보닛 / 와이드 시점 |
| R | 같은 진행 위치에서 코스 중앙으로 복귀, 시간 3초 차감 |
| Esc / P | 일시정지 / 계속 |
| M | 소리 켜기 / 끄기 |

터치 화면에서는 방향·가속·제동·드리프트 버튼이 나타납니다. 표준 게임패드는 왼쪽 스틱/방향 패드로 조향, RT/A 가속, LT/B 제동, X 드리프트, Y 시점, Start 시작/일시정지를 사용합니다. 브라우저 창을 벗어나면 게임이 자동으로 일시정지합니다.

## 실행과 제작

저장소 루트에서:

```bash
python -m http.server 8765
```

`http://localhost:8765/engine/arcade/`를 엽니다. 외부 CDN, npm 설치, 모델 다운로드가 필요하지 않습니다.

```bash
node --test engine/arcade/race-core.test.mjs
cd engine
python -X utf8 tools/build.py
python -X utf8 arcade/build.py
```

첫 빌드 명령은 기존 엔진의 배포본·개발본과 새 모드 진입점을 갱신합니다. 두 번째는 동일한 게임 소스, 스타일, Three.js를 `arcade/play.html` 한 파일로 합칩니다. `play.html`은 다운로드 후 오프라인에서도 실행할 수 있습니다.

| 파일 | 역할 |
|---|---|
| `race-core.js` | 120Hz 고정 스텝 주행, AI, 충돌, 슬립스트림, 순위, 랩, 시간, 경기 상태 |
| `world.js` | 같은 트랙 좌표를 따르는 3D 코스·차량·주변 풍경, 카메라 |
| `renderer.js` | WebGL 렌더러와 자동 Canvas 소프트웨어 렌더러 |
| `app.js` | 키보드·터치·게임패드, HUD, 메뉴, 기록 저장 |
| `audio.js` | Web Audio 합성 엔진음, 타이어음, 카운트다운·체크포인트 효과음 |
| `index.html`, `arcade.css` | 반응형 화면 구성 |
| `race-core.test.mjs` | 16개 결정적 시뮬레이션 검사 |
| `project.json` | 요청받은 픽셀 240, 화면 맞춤, 맑음, 11:30 설정 |
| `../src/89_arcade_launcher.js` | 기존 엔진 플레이 모드 메뉴의 게임 진입점 |

`?style=pixel&raster=240&pixelFit=auto`가 요청 설정입니다. 화면의 화질 버튼은 240 픽셀, 480 픽셀, 클린 3D를 순환합니다. `?renderer=software`는 동일한 장면의 Canvas 투영 경로를 명시적으로 선택합니다. `?touch`는 데스크톱에서도 터치 버튼을 표시합니다.

## 구현 경계

기존 섬의 Rapier 차량과 160km/h 해안 타임 트라이얼은 유지했습니다. 새 스피드웨이는 독립 진입점에서 전용 주행 모델을 사용하므로 섬 지형·캐릭터 자산을 만들 필요가 없습니다. `?mode=arcade`는 엔진 초기화 전에 새 게임으로 이동합니다.

WebGL을 만들 수 없는 브라우저에서도 동일한 Three.js 메시와 카메라를 Canvas에 투영해 플레이합니다. 소프트웨어 렌더러는 깊이 버퍼 대신 삼각형 정렬을 사용하므로 일부 겹치는 폴리곤의 표현은 WebGL과 다를 수 있습니다. 현재 게임은 싱글플레이 1코스·1차량이며, 온라인 대전이나 외부 자산 가져오기는 포함하지 않습니다.

## 검증

자동 검사 14개는 트랙 연결, 카운트다운, 30/60/144FPS에서 동일한 결과, 가속·제동·기어·드리프트, 일시정지, 복귀 시 진행 보존, 순차 관문·랩, 3랩 완주, 시간 초과, 슬립스트림, 차량·벽 충돌, 재시작, 잘못된 입력 처리를 다룹니다. 자동 조향 운전자는 약 74.315초에 9개 관문을 통과하며 완주했습니다. 이 수치는 자동 검사 결과이며 사람이 직접 플레이한 기록은 아닙니다.

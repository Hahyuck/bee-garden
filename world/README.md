# one world — 요새, 산, 정원을 하나의 세계로

**보기: https://hahyuck.github.io/bee-garden/world/**

세 작품을 한 공간에 놓았습니다. 바다 위 요새(seafort)가 있고, 그 뒤 바다에 산섬이 서 있고, 산자락 테라스에 정원이 있습니다. 하늘·날씨·빛은 요새의 것 하나를 모두가 같이 씁니다.

| 키 | 보는 방식 |
|---|---|
| `0` | 이어 보기(기본): 요새 투어 → 정원으로 날아가 벌의 비행 → 등산로 다섯 장면 → 정상 → 반복 |
| `1` | 요새 투어 |
| `2` | 벌의 비행 (벌집 → 잔디 → 토끼풀 → 코스모스 → 고양이 → 해바라기 → 귀가, 75초) |
| `3` | 산행 (테라스에서 정상까지 걸어 오름. `↑` 빠르게, `↓` 뒤로) |
| `4` | 운전 (섬을 한 바퀴 도는 해안 도로, 약 2.8km. 랩 타임 기록) |
| `W A S D` + 마우스 | 어디서든 자유 카메라로 전환 (`Q`/`E` 하강/상승, `Shift` 가속, `R` 투어로 복귀) |

클릭하면 소리, `M` 음소거, `Space` 일시정지.

어느 방식에서든: `F` 보는 방향으로 돌 던지기, `G` 앞에 벌통 상자 놓기, `X` 보는 곳에 폭발.

날씨: `5` 맑음, `6` 비, `7` 눈, `8` 혹한, `9` 자동(엔진의 시간 흐름을 따름).

소스를 고쳐 가며 쓰는 방법은 [ENGINE.md](ENGINE.md)에 있습니다. `dev.html`은 소스 파일을 하나씩 불러오는 개발용 페이지입니다.

## 운전 조작

| 입력 | 동작 |
|---|---|
| `W` / `↑` | 가속 |
| `S` / `↓` | 브레이크, 멈춘 뒤 계속 누르면 후진 |
| `A` `D` / `←` `→` | 조향 |
| `Space` | 핸드브레이크 |
| `C` | 카메라 (가까운 추격 · 먼 추격 · 보닛) |
| `V` | 누르는 동안 뒤 보기 |
| `R` | 가장 가까운 도로로 복귀 |
| `Esc` | 일시정지와 조작법 |

게임패드(표준 배치): RT 가속, LT 브레이크, 왼쪽 스틱 조향, A 핸드브레이크, Y 카메라, X 복귀, RB 뒤 보기, Start 일시정지.

출발선을 지나면 랩 타이머가 시작되고, 최고 기록은 브라우저에 저장됩니다. 뒤집히거나 바다에 빠지면 자동으로 도로에 돌아옵니다.

## 구성

- 요새 원본은 [cammykd/seafort](https://github.com/Hahyuck/cammykd/tree/master/seafort)이며, 이 폴더의 `src/`는 그 소스에 아래 모듈을 더한 것입니다.
- `src/40_fxkit.js` — 벌의 정원과 산행의 모델링·셰이딩을 한곳에 모은 묶음. [FXKIT.md](FXKIT.md) 참고.
- `src/42_island.js` — 산섬: 높이 함수, 스스로 길을 찾는 등산로(지그재그), 숲·수목한계선·풀밭·바위, 정상의 돌탑. 해안 도로(지형을 깎고 메워 놓음)와 그 표면, 거리에 따라 세 단계로 바뀌는 숲, 카메라를 따라오는 풀도 여기 있습니다.
- `src/44_garden.js` — 정원: 1:100으로 놓은 잔디·꽃·벌집·고양이·벌, 그리고 벌의 눈(스프링 시선, 끊어 도는 고개, 제자리 비행).
- `src/02_config.js` — 차·물리·날씨의 조절 값을 모은 설정.
- `src/41_weather.js` — 날씨. 아래 "날씨" 참고.
- `src/85_phys.js` — 세계 공용 물리. 강체 엔진 [Rapier](https://rapier.rs) 0.19.3(Apache-2.0)을 CDN에서 불러옵니다. 아래 "물리" 참고.
- `src/87_drive.js` — 운전: 바퀴 네 개의 서스펜션과 타이어 접지(마찰원), 앞바퀴 굴림, 5단 자동 변속, 추격 카메라, 랩 계측, 일시정지, 게임패드, 엔진음.
- `src/92_journey.js` — 네 가지 보는 방식과 그것을 잇는 여정.
- `src/90_main.js`(빌드 단계 두 줄 추가), `src/shell.html`(표지 문구)만 원본에서 고쳤습니다.

빌드: `python tools/build.py` → `dist/crimson-loong.html` (이것을 `index.html`로 복사). Windows에서는 `PYTHONUTF8=1`이 필요합니다.

## 크기 맞추기

요새와 산은 미터 단위이고 벌은 1.4cm입니다. 정원의 원형은 센티미터로 모델링해 1:100으로 배치했고, 벌의 눈일 때만 카메라의 근접 한계를 4mm로 낮춥니다. 산은 원작의 2,488m 대신 요새 뒤 바다에 선 약 350m의 섬으로 줄였습니다.

## 도로 표면과 숲의 단계

- **도로**: 골재 알갱이, 구간마다 색이 다른 재포장과 이음매, 메운 균열, 굽이 안쪽으로 붙는 주행선의 타이어 자국, 닳은 차선과 출발선, 굽이 안쪽 연석, 자갈 갓길, 물웅덩이를 한 셰이더에서 겹쳐 그립니다. 비가 오면 전체가 젖고 접지력이 줄어듭니다.
- **숲**: 130m 안은 늘어진 가지 층이 두 겹인 나무, 440m 안은 단순한 가지 층, 그 밖은 카드 두 장에 그린 실루엣입니다. 18m 안의 나무에는 가지 끝마다 바늘잎 다발이 붙습니다.

## 물리

`Phys`는 한 대상이 아니라 세계 전체가 같이 쓰는 강체 세계입니다. 1/240초 고정 스텝으로 돕니다.

- **단단한 것**: 섬의 지면(보는 이 주변 32m 타일을 삼각형 메시로 흘려 넣음), 나무 줄기, 큰 바위.
- **움직이는 것**: `Phys.spawn(kind, x, y, z, {q, v, color})`으로 만든 상자·통·고깔·돌. 다른 모듈이 만든 몸체는 `Phys.adopt`로 맡깁니다(차가 그렇게 들어옵니다).
- **작용하는 것**: 중력, 접촉과 마찰, 바다(수면 아래 부력과 저항: 통은 뜨고 돌은 가라앉음), 폭풍의 바람(가벼운 것이 밀림), 폭발(`Phys.blast`).
- **끼어들기**: 스텝마다 자기 힘을 넣으려면 `Phys.pre.push(h => ...)`. `Phys.ray(o, d)`로 광선 검사.
- 차는 이제 이 세계의 강체입니다. 바퀴의 스프링·타이어 힘만 직접 계산해 충격량으로 넣고, 충돌·전복·밀려나는 물체는 엔진이 풉니다. 코스에는 고깔, 통, 벌통 상자 더미가 놓여 있습니다.
- 엔진을 불러오지 못하면(오프라인 등) 세계는 물리 없이 돌고, 차는 이전의 자체 적분으로 달립니다.

## 날씨

`Weather`는 기온, 바람, 비, 내리는 눈, 쌓인 눈, 빙결, 젖음을 하나의 상태로 갖고, 세계의 나머지가 그것을 읽습니다.

- **눈**: 기온이 영하이면 눈이 내려 하늘을 향한 면부터 얼룩지게 쌓이고(지면, 도로, 나무, 풀), 기온이 오르면 녹으면서 땅을 적십니다. 비는 눈을 씻어 냅니다. 도로에서는 타이어가 지나는 선에 눈이 얇게 남습니다.
- **빙결**: 영하에서 젖은 곳이 업니다. 웅덩이가 하얗게 얼고 도로가 반들거립니다.
- **비**: 엔진의 폭풍과 비를 그대로 쓰고, 흙이 어두워지며 번들거리고 등산로가 진흙빛이 됩니다.
- **바람**: 폭풍과 추위에 따라 세지고, 눈송이를 실어 나르고, 가벼운 물체(고깔, 빈 통)를 밉니다.
- **접지력**: 젖음, 눈, 빙판에 따라 타이어 접지력이 줄고 눈길에서는 구름 저항이 늡니다.
- **되비친 빛**: 해의 색에 땅의 색을 곱한 빛을 아래쪽 보조광에 더합니다. 눈이 쌓이면 어두운 흙빛 대신 밝고 찬 흰빛이 아래에서 올라옵니다. 언리얼의 루멘처럼 빛을 추적하는 것이 아니라, 첫 번째 되비침을 근사한 값입니다.

## 아직 안 된 것
- 눈과 빙결은 섬(지면, 도로, 식생)에만 보입니다. 요새와 마을의 벽·지붕, 바다에는 아직 쌓이거나 얼지 않습니다.
- 실시간 전역 조명(빛 추적, 화면 공간 반사광)은 없습니다. 위의 되비친 빛은 장면 전체에 한 값으로 들어갑니다.
- 눈에 바퀴 자국이나 발자국이 패이지 않고, 눈 더미가 물체를 막지 않습니다.

- 섬과 정원은 요새의 그림자 맵 범위(타워 주변 310m) 밖이라 태양 그림자가 없습니다. 풀과 나무는 높이에 따른 음영만 받습니다.
- 벌의 눈에는 원작의 어안 렌즈·접사 심도·겹눈 모드가 아직 연결되지 않았습니다(셰이더는 FXKit에 있음).
- 연못·잠자리·잉어, 개울과 다리, 안개 숲, 구름바다는 옮기지 않았습니다.
- 벌의 날갯소리, 발소리, 음악은 없습니다(요새의 바다·바람·갈매기 소리만 납니다).
- 자유 카메라와 산행에는 충돌이 없습니다. 요새와 마을 건물, 정원의 물체는 아직 물리 세계에 없습니다(섬의 지면·나무·바위만 단단합니다).
- 경쟁 차, 리플레이, 타이어 자국은 없습니다.

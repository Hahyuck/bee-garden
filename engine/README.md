# garden engine — 벌의 정원 방식으로 세운 독립 엔진

벌의 정원의 하늘·날씨·카메라를 토대로 만든 브라우저용 월드 엔진입니다. Three.js와 Rapier 위에서 지형을 생성하고, 실측한 암석·흙 재질과 뼈대가 있는 캐릭터를 같은 빛으로 그립니다.

**사용 안내: [GUIDE.md](GUIDE.md)** — 실행하고 고치기, 세계 바꾸기, 물리와 효과, 게임 규칙 넣기, 게임 엔진으로 활용하는 방법을 예시와 함께 정리했습니다. `0` 키의 "통+돌 랜덤 낙하"가 그 예시 게임입니다(`src/89_example_collect.js`).

자유시점은 해안 정원의 바위 앞에서 시작합니다. 옆면에는 갈라진 암반의 결이 이어지고, 아래로 내려가면 흙에 파묻힌 자갈이 보입니다. [오후의 해안 정원](https://hahyuck.github.io/bee-garden/engine/?day=16.15&still&weather=clear) · [캐릭터 직접 조작](https://hahyuck.github.io/bee-garden/engine/?mode=actors&day=16&weather=clear)

## 실행

```bash
python -m http.server 8765
```

- `engine/dev.html` — 소스 파일을 하나씩 불러옵니다. 고치고 새로고침하면 반영됩니다.
- `engine/index.html` — 한 파일로 합친 배포용. `python tools/build.py`로 다시 만듭니다(Windows는 `PYTHONUTF8=1`).

주소 옵션: `?mode=free|bee|fps|drive|flight|actors`, `?weather=clear|rain|snow|frost|auto`, `?day=17.5`(시각), `?still`(시간 멈춤), `?low`, `?cam=x,y,z,tx,ty,tz`.

## 로그인한 AI에서 게임 만들기

1. 게임을 플레이하다 하단 **제작할 게임**에 아이디어를 적고 **GPT · Codex** 또는 **Claude Code**를 선택합니다. 기존 게임을 고치려면 **설정 → 현재 게임 개편**을 고릅니다.
2. **AI로 열기**를 누르면 요청문에 엔진 저장소, 장면 미리보기 주소, 현재 모드·화면 표현·날씨·시각·프로젝트 설정이 담깁니다. 게임 탭으로 돌아와 계속 플레이할 수 있습니다.
3. **Codex**는 데스크톱 앱의 새 작업창을 엽니다. Git 원격 주소가 일치하는 작업공간을 사용하므로 처음에는 이 저장소의 폴더를 열어 주세요. **Claude Code**는 새 브라우저 탭에 GitHub 저장소를 지정합니다. 해당 계정에서 처음 사용한다면 GitHub 연결과 환경 설정을 마칩니다. 요청을 확인하고 **보내기**를 누르면 제작을 시작합니다. [Codex 앱 링크](https://learn.chatgpt.com/docs/app/commands) · [Claude Code 웹 연결](https://code.claude.com/docs/en/web-quickstart#pre-fill-sessions)
4. Codex 앱이 없는 기기에서는 **요청문 복사 → Codex 웹 열기**로 같은 내용을 전달할 수 있습니다. 링크 길이를 초과하는 큰 프로젝트는 전체 요청문을 복사할 수 있습니다. 브라우저에만 추가한 GLB 파일은 별도로 첨부하거나 저장소에 넣으세요.

## 저장소 링크와 프롬프트로 게임 만들기

1. [엔진을 실행](https://hahyuck.github.io/bee-garden/engine/)하고 상단의 **게임 비주얼**를 엽니다. **픽셀 / 2D / 2.5D / 3D / 클린 픽셀 3D / 흑연명암 3D / 디오라마 / 가우시안** 중 하나를 고릅니다. 픽셀 화면은 240×160, 360×240, 480×320, 600×400, 720×480을 지원하며 세로 화면에서는 두 축을 바꿉니다.
   2D에서는 **클린 도트**와 **단색 도트**, 2.5D에서는 **HD-2D 라이트**와 **디더링**을 고릅니다. 보행 중 2D와 2.5D는 마우스나 한 손가락으로 끌어 회전하고 휠을 위·아래로 굴려 확대·축소합니다. WASD는 회전한 화면의 방향을 따릅니다. FPS 조준과 잠망경 시점은 각 모드가 제어합니다. 가우시안 소프트는 화면에 가우시안 블러를 적용하는 필터입니다.
   **픽셀 Fit**에는 비율을 유지하며 가장자리만 보간하는 **화면 맞춤**과, 화면의 한 도트를 같은 수의 기기 픽셀로 표시하는 **정수배**가 있습니다. 두 방식 모두 3인칭 이동 카메라를 격자에 맞추고 화면에 여백이 생길 수 있습니다. 스타일 기본값에서는 2D 클린 도트에 화면 맞춤이 적용됩니다. URL이나 프로젝트 JSON의 `pixelFit` 값은 `auto`, `fit`, `integer`, `off`입니다.

2. 캐릭터나 오브젝트 용도와 실제 높이를 정하고 GLB 파일을 고릅니다. 캐릭터는 V 모드에서 조종할 수 있습니다. 기본 애니메이션 이름(idle, walk, run, jump, crouch)을 찾아 연결합니다. 애니메이션이 없는 모델도 이동과 점프가 가능합니다. 소품은 바라보는 방향에 배치하고 지면과 충돌을 연결합니다. 모델과 텍스처를 포함한 glTF 2.0 GLB를 사용하세요. 로컬 모델은 해당 브라우저에 저장됩니다.
3. **만들고 싶은 게임**에 목표, 조작, 성공 조건을 입력하고 **제작 프롬프트 복사**를 누릅니다. 복사한 글과 모델 파일을 저장소를 편집할 수 있는 AI 코딩 도구에 전달합니다. 예를 들어 “잠수함으로 세 산호 군락을 탐사하고 거북이를 관찰하면 귀항하는 2.5D 게임을 만들어줘”라고 쓸 수 있습니다.
4. 같은 장면을 다른 사람에게 배포하려면 **프로젝트 JSON**을 받아 `engine/project.json`에, 원본 GLB를 `engine/assets/project/`에 넣고 함께 커밋합니다. 경로는 JSON을 기준으로 해석합니다. 배포 주소에 `?project=project.json`을 붙여 실행합니다. [기존 에셋으로 만든 예제](https://hahyuck.github.io/bee-garden/engine/?project=project.example.json) · [실제 설정 파일](project.example.json)

게임 규칙을 구현할 때 `src/88_modes.js`의 `Modes.add`로 모드를 등록하고, 모드별 `enter / step / leave`에서 씬과 입력을 관리합니다. `dev.html`로 개발하고 `python -X utf8 tools/build.py`로 배포용 `index.html`을 재생성합니다. 기존 모드에 프로젝트 데이터만 추가할 때는 JSON과 GLB를 그대로 사용할 수 있습니다.

GLB를 내보낼 때 메시 압축을 끄고 텍스처는 PNG나 JPEG로 포함하세요. 현재 로더는 별도 디코더가 필요한 Draco·Meshopt·KTX2 압축을 지원하지 않습니다.

|---|---|

| `0` | 통+돌 랜덤 낙하. 해안 도로에서 통과 돌이 시선 앞쪽에 떨어지며, 이동하면서 관찰할 수 있습니다. |
| `V` | WASD·방향키 이동, W + Shift + Space 달리기 점프, C 앉기·일어서기. 높은 벽을 향해 전진하며 Space로 잡고 W/S로 오르내립니다. Space를 다시 누르면 놓습니다. 오른쪽 위에서 캐릭터를 바꿉니다. 모바일은 왼쪽 스틱과 오른쪽 동작 버튼을 씁니다. |
| **도구 → 캐릭터 · 모델 샘플** | 사람을 바꾸거나 소품·건물·자동차·비행기를 골라 정원에서 돌려 봅니다. 각 모델의 원본과 이용 조건을 함께 볼 수 있습니다. |
| `K` `I` `N` `Y` `9` | 맑음 · 비 · 눈 · 혹한 · 자동 날씨 |
| `[` `]` / `T` | 시각을 한 시간씩 옮기기 / 시간 흐름 멈춤 |
| `F` `G` `X` | 돌 던지기 · 벌통 상자 놓기 · 폭발 |
| `M` | 소리 |
| `H` | 엔진 활용법(화면 안 안내서, 예시를 눌러 바로 실행) |
| `L` | 라이팅 비교 패널 보이기/숨기기 |
| `B` | 벌 시점에서 겹눈 보기 |

| 모드 | 시작과 조작 |
|---|---|
| 3 FPS | 마우스를 움직여 중앙 조준점을 돌립니다. 화면 가장자리에 두면 그 방향으로 계속 회전합니다. 왼쪽 클릭은 발사, 오른쪽 클릭 또는 R은 재장전입니다. WASD로 이동하고 Space로 점프합니다. Esc를 누르면 일시정지하고 커서가 나타납니다. **계속하기**를 클릭하면 다시 조준합니다. |
| 4 레이싱 | 운전석 옆에서 E나 O를 누릅니다. 모바일에서는 **문 열고 출발 준비**를 누릅니다. 문이 열리면 바로 3초 카운트다운이 시작됩니다. W 가속(최고 160 km/h), S 제동·정차 후 다시 누르면 후진, 가속 중에도 A/D 또는 ←/→로 조향, Space 제동·조향을 함께 누르면 드리프트, C 시점, B 후방 보기, R 코스 복귀. 자동 변속으로 체크포인트 세 곳과 결승선을 통과하는 한 바퀴 타임 트라이얼입니다. |
| 5 경비행 | 활주로의 경비행기에 다가가 E로 탑승합니다. W/S로 출력을 조절하고 A/D로 지상 조향·공중 선회, 마우스를 위/아래로 움직이거나 ↑/↓로 기수를 조절합니다. 착륙 후 Space로 제동합니다. E는 모든 속도에서 하차하며 공중에서 낙하산이 펼쳐집니다. R로 활주로에 복귀합니다. |
| 6 배 | W/S 전후진, A/D 조타로 여섯 개 부표를 순항합니다. 전진 속도가 붙으면 양옆에 물보라가 퍼지고 회전하는 선미 프로펠러 뒤에 포말이 남습니다. 항속, 방위, 다음 부표까지의 거리를 계기로 봅니다. |
| 7 잠수함 | W/S 전후진, A/D 선회, Q 잠항, E 부상. P를 누르면 선체가 잠망경 수심 약 2.05m로 이동한 뒤 렌즈 시점으로 이어집니다. 주변 해역마다 다른 어군이 나타납니다. 드래그로 관측 방향을 돌리고 Z로 1배/3배를 전환합니다. |
| 8 낚시 | 선택한 사람 캐릭터가 부교 위에서 양손으로 낚싯대를 듭니다. 개구리를 선택하면 기본 낚시꾼이 등장합니다. 낚싯대와 미끼를 고르고 A/D로 방향을 정합니다. Space로 던지고 찌가 잠길 때 Space로 챔질합니다. 길게 누르거나 휠을 위로 돌려 감고, 장력이 높아지면 놓습니다. 잡은 물고기는 어망에서 확인합니다. |

모든 모드에서 왼쪽 위 미니맵이 현재 위치와 방향을 표시합니다. 항해와 낚시에서는 다음 부표와 찌가 각각 금색으로 표시됩니다. 자동차 백미러는 후방 카메라 영상에 현재 화면 필터를 적용합니다.

지형을 구성하는 삼각형에서 발밑 높이를 구합니다. 나무·바위·벌통, 탑승 대기 중인 탈것과 사격장 받침에 충돌체를 배치했습니다. 사람은 자세에 따라 크기가 바뀌는 캡슐로 장애물을 검사하고, 전시 건물의 문과 계단은 모델 자체의 삼각형을 사용합니다. 물리엔진 Rapier 0.19.3은 배포 파일에 포함됩니다. ## 라이팅 비교

왼쪽 위 라이팅 패널은 `L`로 여닫습니다. 벌통 받침 아래에서 **접촉 음영**을 켜고 끄면 지면과 물체가 만나는 좁은 틈의 밝기를 비교할 수 있습니다. [비 갠 뒤 해안 도로](https://hahyuck.github.io/bee-garden/engine/?wet&weather=clear&still&day=16.6&cam=-415.647,12.942,-139.209,-424.934,10.75,-139.007,62,.11)에서는 **젖은 노면**을 눌러 바퀴 자국에 비치는 하늘을 살펴보세요. `6`을 누르면 다시 비가 오고, `K`를 누르면 비가 그치면서 고인 물도 서서히 빠집니다.

그림자, 공기, 땅의 되비침, 빛 필드, 빛기둥, 블룸, 노출 적응, 필름도 각각 비교할 수 있습니다. `기본 조명`과 `?look=plain`은 해와 하늘·땅 보조광, 그림자로 시작합니다. 각 스위치는 `G.look`과 `84_lookpanel.js`의 `PARTS`에 있습니다.

## 공용 약속

- **`G`** — `G.scene`, `G.camera`, `G.sun`, `G.hemi`, `G.t`(초), `G.day`(시각 0–24), `G.snd`, `G.drive`, `G.U`(빛과 공기의 유니폼).
- **`G.tick.push((t, dt) => ...)`** — 매 프레임 불립니다.
- **`patch(material, s => ..., key)`** — three.js 표준 재질에 셰이더 조각을 끼웁니다. 시간·바람·날씨 유니폼이 자동으로 붙습니다.
- **모듈 모양** — `const Name = (() => { ...; return { build, ... }; })();` 최상위 이름은 모든 파일이 공유합니다.

## 자주 할 일

**새 시스템**: `src/NN_name.js`를 쓰고 `90_main.js`의 `STEPS`에 한 줄을 더한 뒤 빌드를 한 번 돌립니다(`dev.html`의 목록이 갱신됩니다).

```js
['이름', 2, async p => Name.build(scene, p)],
```

**새 모드**: `88_modes.js`의 `MODES`에 `{ name, enter(), leave(), step(camera, dt) }`를 더합니다. `step`이 카메라를 놓고 화면 아래에 보일 한 줄을 돌려줍니다. 심도가 필요하면 `Post.lens.focus`와 `Post.lens.aperture`를 정합니다.

**물리**: `Phys.spawn(kind, x, y, z, {q, v, color})`, `Phys.blast(x, y, z)`, `Phys.ray(o, d)`, `Phys.pre.push(h => ...)`, `Phys.adopt(body, {vol, r, lift})`. 새 종류는 `85_phys.js`의 `KIND`에 한 줄.

**날씨에 반응**: JS는 `Weather.S`, 셰이더는 `GLSL_WX`의 `uWx`(적설, 빙결, 젖음, 바람)와 `wxCover()`.

**효과**: `FX.trail(a, b, 폭, 종류)`(0 먼지, 1 물보라·눈·타이어 연기, 2 불꽃), `FX.blast(x, y, z, 반경)`, `LightField.hot(x, y, z, 세기)`, `Post.heat(위치, 세기)`.

**하늘을 비추는 표면**: `GLSL_NOISE + GLSL_SKY`를 넣고 `skyCol(방향, 해 원반 0|1)`을 부릅니다(바다가 그렇게 합니다). 유니폼은 `Sky.U`.

**땅 묻기**: `Island.surf(x, z)` → `[높이, 종류]`. 눈에 보이는 땅, 바퀴, 물리 타일이 모두 이 함수를 씁니다.

## Pixel Aleste에서 가져온 것

[Pixel Aleste](https://hahyuck.github.io/rgb-world-play/pixel-aleste/)의 셰이딩 가운데 이 엔진에 쓸모 있는 다섯 가지를 옮겼습니다.

| 효과 | 여기서 하는 일 |
|---|---|
| 조도 필드(간접광) | 숲 아래가 어두워지고, 해 받은 숲 가장자리가 옆 땅에 빛을 돌려줍니다. 눈이 쌓이면 그 빛이 희어집니다 |
| 화면 공간 빛기둥 | 해가 낮을 때 나무와 능선 사이로 빛줄기가 샙니다 |
| 열 아지랑이 | 폭발 자리의 공기가 일렁입니다 |
| 폭발 껍질과 고리 | `X` 폭발이 결이 있는 껍질, 퍼지는 고리, 불꽃 띠로 그려지고 주변을 잠깐 밝힙니다 |
| 띠(트레일) | 차의 뒷바퀴가 자갈·풀·모래에서 먼지를, 눈길과 젖은 길에서 물보라를, 미끄러질 때 연기를 냅니다 |

옮기지 않은 것: 구름·화염 아틀라스를 쓰는 효과(텍스처 파일이 필요), 음속 응결 고리와 날개 끝 비행운(비행 모드를 만들 때 쓸 것), 먼 공기 산란(이 엔진의 높이 안개가 같은 일을 함).

## 아직 안 된 것

- 빛은 해(달) 하나와 하늘·땅 보조광, 땅에서 한 번 되비친 빛의 근사, 그리고 숲만 아는 빛 필드입니다(바위·지형·물체는 필드에 없음). 빛 추적 방식의 전역 조명, 반사 프로브, 화면 공간 반사는 없습니다. 금속 재질에 비칠 환경 맵도 아직 없습니다.
- 구름은 하늘에 그린 평면 한 겹입니다(부피 구름이 아님). 구름 그림자가 땅에 지지 않습니다.
- 바다에 굴절과 물속 장면이 없습니다. 물체가 물에 닿아도 물보라가 없고, 물에 비치는 것은 하늘뿐입니다(섬과 물체는 비치지 않음).
- 자유시점은 지면 위로 제한되며 물리 엔진이 활성화되면 장애물과 충돌합니다.
- 눈에 자국이 패이지 않습니다. 밤에는 차의 전조등이 길을 비추지 않습니다.
- `world/`의 요새와 마을은 여기 없습니다(그쪽은 Crimson Loong 층에 기대고 있습니다).
